# Branch Cash Handling Procedure

**Document ID:** BM-CASH-001 | **Version:** 1.0 | **Effective:** 2026-01-01

*SYNTHETIC TRAINING DOCUMENT - for educational simulation only.*

## 1. Teller checks

The teller verifies the customer's identity before accepting or paying cash. Cash is counted twice in front of the customer and the receipt is retained according to branch procedure.

## 2. Shortages and overages

Any till shortage or overage is reported to the branch supervisor before the end of the working day. The employee must not use personal funds to balance a till.
